# Air Quality Index Prediction Using Ridge and Lasso Regression

This project predicts the Air Quality Index (AQI) using Machine Learning techniques.

The project uses **Ridge Regression** and **Lasso Regression** to predict AQI based on air pollution parameters such as **PM2.5, PM10, NO₂, SO₂, CO, and O₃**.

The dataset is cleaned and preprocessed before training the models. The models are evaluated using **MAE, MSE, RMSE, and R² Score**.

The main objective of this project is to compare Ridge and Lasso Regression and identify which model provides better AQI prediction.

* Matplotlib
